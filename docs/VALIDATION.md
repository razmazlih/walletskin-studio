# אימות גרסת השיתוף 0.3.2

45 בדיקות Python ובדיקות Swift עברו בהכנת גרסת השיתוף. בדיקות Swift כיסו PNG/JPEG, כיוון EXIF, התאמת תמונה, שימור המקור ושיוך מדויק של תמונה לכרטיס ולמכשיר. קידוד HEIC לא היה זמין בסביבת הבדיקה ולכן דולג.

מסלולי המכשיר והכתיבה נבדקו באמצעות מוקים; אין כאן ראיה להחלה מוצלחת באייפון. ראו DEVICE-VALIDATION.md למגבלות האימות הפיזי.

קובצי השיתוף כוללים מקור, בדיקות ותיעוד בלבד. מתקין השיתוף נבנה מהמקור ללא קובצי מטמון, תמונות משתמש, Recovery או יומני מכשיר.

עדכון 0.3.2: נוספו הדרכת התחלה, קפיצה לסעיפים, שלושה עיצובים מקוריים ותפריט התאמות אופציונלי. האפליקציה נבנתה ל־arm64 ו־x86_64. בדיקת ממשק אמיתי במצב הדגמה אימתה מעבר לסעיף העיצוב ובחירת עיצוב עם תצוגה מקדימה. התקנת רכיב Apple במק נקי לא נבדקה בפועל, ואין כאן בדיקת התקנה במק של חבר.
