# בדיקות iPhone פיזי שנותרו

> גרסה 0.2.1 חוסמת כתיבה. שורות החלה/ניקוי להלן הן דרישות עתידיות בלבד, ואינן הוראות לבצע שינוי בגרסה 0.2.0. לפני החזרת כתיבה יש להשלים את התנאים ב־APPLY-FEASIBILITY.md.

לא אומתה כתיבת כרטיס אמיתית בסביבת הבנייה. בדקו רק מכשיר אישי מורשה ובגרסה שבטווח המתועד; קראו את חלון האישור והיעדר שחזור לפני כל שינוי. אין צורך לפגוע בהגנות macOS/iOS.

| בדיקה | תוצאה נדרשת |
|---|---|
| אין iPhone | רשימה ריקה; אין כרטיסים פעילים או הצלחה |
| USB נעול / לא מהימן | הנחיות לפתיחה ו־Trust ב־Finder; אין צימוד אוטומטי |
| Trust הושלם | דגם וגרסה אמיתיים מוצגים ללא פרטי תשלום |
| Wi-Fi בלבד | אינו מוצע כיעד USB |
| גרסה חדשה / beta / לא ידועה | החלה חסומה ללא כתיבה |
| פתיחת כרטיס אחד בסריקה | מזהה נכס חי במכשיר הנכון; המספר המקומי אינו סדר Wallet |
| מידע private / אין אירועים | אין כרטיסים מומצאים |
| שני מכשירים | מעבר מכשיר מנקה בחירה; שיוכים ותוקף סריקה לא חוצים מכשירים |
| תמונות לשני כרטיסים | טעינה חוזרת משחזרת רק את העיצוב המקומי המדויק |
| ביטול אישור | אין רכיב כתיבה שמופעל |
| שינוי בחירה בזמן אישור | הפעולה מבוטלת ונדרש אישור מחדש |
| החלה מאושרת | רק הנכס שאושר נכתב; Books preimage וקובצי הביניים מנוקים בהצלחה |
| סיום העברה | הודעה שהופעת התמונה ב־Wallet עדיין דורשת אימות |
| סגירה ופתיחה של Wallet | בדיקת התמונה בכרטיס שנבחר, ואז אישור ידני באפליקציה |
| ניתוק לפני כתיבה | אין שינוי ואין הצלחה |
| כשל בזמן העברה | אין הצלחה; ייתכן שינוי חלקי; נשמר מידע התאוששות ונחסמים ניסיונות נוספים אם ניקוי אינו מאומת |
| mock | מסומן בבירור; אין גישה לאייפון |

אל תיזמו ניתוק בזמן כתיבה באייפון היומיומי כדי לבדוק תקלה. בדיקות תקלות אוטומטיות משתמשות במוקים; אימות פיזי של תרחישי הפרעה דורש מכשיר בדיקה מתאים והיערכות מראש.

תעדו דגם, OS/build, commit ושלב שנבדק. אל תצרפו UDID, מזהי כרטיסים, מטא־דאטה Books או אירועים גולמיים לדיווחים ציבוריים. אין תהליך מוכח לשחזור תמונת המקור בגרסה זו.
