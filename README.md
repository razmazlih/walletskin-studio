# WalletSkin Studio 0.3.1

אפליקציית macOS בעברית ובאנגלית לעיצוב תמונות כרטיסי Wallet, עם חיבור USB וגילוי כרטיסים באמצעות AirCard.

**מצב ניסיוני:** החלת תמונה על iPhone אינה מאומתת מקצה לקצה. המנגנון הלא רשמי כותב גם לנתוני Books/Media ועלול לדרוס נתונים או להשאיר שינוי חלקי. אין שחזור מאומת לתמונת Wallet המקורית. כל החלה דורשת גילוי חי ובחירה ואישור מפורשים. זיהוי USB ובדיקות מקומיות אינם הוכחת שינוי מוצלח באייפון.

## התקנה לחברים

נדרש Mac עם macOS 14 ומעלה, Apple Silicon או Intel. זו אפליקציית Mac; אינה מותקנת ישירות באייפון.

1. היכנסו לגיטהאב בחשבון שקיבל גישה למאגר הפרטי וקבלו את ההזמנה.
2. פתחו את Releases והורידו את `WalletSkin-Studio-0.3.1.dmg`.
3. פתחו את הקובץ וגררו את WalletSkin Studio אל Applications.
4. הבנייה חתומה ad-hoc בלבד, ללא חתימת Developer ID וללא notarization. macOS עשוי לחסום פתיחה. אחרי בדיקת המקור, השתמשו בפתיחה המאושרת דרך הגדרות המערכת → פרטיות ואבטחה, אם היא זמינה. אין צורך לכבות Gatekeeper או SIP.
5. לעיצוב וייצוא PNG אין צורך באייפון. לחיבור מכשיר: חברו USB, פתחו נעילה והשלימו Trust דרך Finder והאייפון.
6. גלו כרטיס פעיל, הציגו אותו ב-Apple Pay ובחרו את היעד המדויק. אם הזיהוי אינו חד משמעי, בטלו וסרקו שוב.
7. בחרו תמונה ובדקו את התצוגה. קראו את אזהרת ההחלה לפני אישור. אחרי החלה, סגרו ופתחו Wallet ואמתו ידנית את הכרטיס המדויק.

המערכת מקומית, ללא חשבון ענן או API בתשלום. כל חבר יוצר נתוני עבודה משלו. במאגר ובמתקין אין נתוני מכשיר, תמונות אישיות, אישורי סריקה או גיבויי משתמש.

## בנייה מקוד המקור

נדרשים כלי הפיתוח של Xcode, SDK עבור macOS ו-Python 3.

```sh
git clone --recurse-submodules https://github.com/razmazlih/walletskin-studio.git
cd walletskin-studio
./scripts/test.sh
./scripts/build.sh
```

אם שוכפלו המקורות ללא submodule:

```sh
git submodule update --init --recursive
```

המקור של AirCard מקובע ל-`52ba05dca4bdc590672c19d554701f4438e20338`. סקריפט הבנייה מאמת את הגרסה ומפיק אפליקציה לשתי הארכיטקטורות ומתקין DMG. אין לשתף תיקיות Recovery, יומנים או תמונות אישיות בדיווחי תקלות.

## כשל או ניתוק

אם הניקוי לא אומת, נשמר מידע מקומי תחת `~/Library/Application Support/WalletSkin Studio/Recovery` והחלות נוספות נחסמות. זה אינו גיבוי של תמונת הכרטיס. אל תמחקו את התיקייה כדי לעקוף חסימה ואל תפרסמו אותה. בדקו את הכרטיס ב-Wallet ובדקו את הפעולה שנקטעה לפני ניסיון נוסף.
